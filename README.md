# AI BUSINESS

AI BUSINESS is a beginner-first workspace for learning, practicing, and starting a virtual assistant career.

## Product scope
- Guided VA onboarding and learning path
- Skills, workflows, practice tasks, templates and SOPs
- AI Guide integration point
- User workspace and starter portfolio
- Plans, usage metering and credits
- Owner promotions/invitations and operational monitoring
- Supabase-ready authentication and RLS

This repository is intentionally separate from the personal DANVA workspace. No personal client, project, portfolio, memory, or training data is included.
